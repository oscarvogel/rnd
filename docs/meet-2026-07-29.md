# RND — preparación para el meet del 29/07/2026

## Resumen ejecutivo

RND es una aplicación de escritorio para administrar clientes, proveedores,
equipos y empleados; importar pedidos; preparar hojas de ruta; asignar camión
y chofer; e imprimir la documentación operativa.

La versión preparada para la reunión es `2026.7.28.1`. El código, el bundle de
PyInstaller y una instalación silenciosa en un directorio limpio superaron los
chequeos de configuración y de carga de PyQt5.

## Flujo sugerido para la demostración

1. Presentar el objetivo de RND: convertir pedidos de proveedores en hojas de
   ruta asignadas y listas para operar.
2. Mostrar el login y explicar que el acceso depende de los usuarios
   registrados.
3. Recorrer Clientes como ejemplo de maestro operativo.
4. Mostrar Importación de Pedidos:
   - fecha de reparto;
   - empresa proveedora;
   - archivo y hoja de origen;
   - rango de filas;
   - revisión antes de grabar.
5. Mostrar Ver Hoja de Ruta:
   - fecha y ruta;
   - camión y chofer;
   - detalle de pedidos;
   - carga, edición, grabación e impresión.
6. Cerrar con el instalador y los dos chequeos automatizados:

```powershell
dist\main\main.exe --startup-check -i dist\main -a sistema.ini
dist\main\main.exe --ui-check -i dist\main -a sistema.ini
```

## Alcance de la validación

La validación ejecutada no utilizó producción ni una base operativa real. Las
capturas conservaron las vistas reales, pero reemplazaron durante el test los
controles que consultan datos. Esto prueba estructura, carga de widgets,
recursos, textos, versión y empaquetado; no prueba reglas de negocio contra
datos reales.

Antes de entregar el instalador a usuarios finales se recomienda una aceptación
con una base autorizada de prueba que cubra:

1. login con un usuario de prueba;
2. alta y edición de un cliente;
3. importación de una planilla conocida;
4. grabación y recuperación de una hoja de ruta;
5. asignación de camión y chofer;
6. generación e inspección del PDF.

## Riesgos y deuda técnica

- Algunos modelos todavía usan nombres Peewee deprecados (`db_column` y
  `db_table`). Funcionan actualmente, pero conviene migrarlos.
- La importación de modelos crea un cliente Mongo aun en algunos tests; debe
  desacoplarse para eliminar el aviso de recurso abierto.
- PyInstaller informa `Hidden import "sip" not found`; el bundle y el
  ejecutable instalado superaron el chequeo real de PyQt5, por lo que no es un
  bloqueo de esta versión.
- `pyqt5libs` continúa vendorizada. El archivo `pyqt5libs/UPSTREAM_COMMIT`
  registra su procedencia, pero a futuro conviene automatizar la actualización.
- La cobertura automática protege empaquetado, startup, UI básica, SMTP e
  higiene. Las reglas de negocio principales todavía necesitan más tests.

## Próximos pasos recomendados

2. Documentar un juego pequeño de datos de demo repetible.
3. Agregar tests de importación y armado de hoja de ruta.
4. Eliminar las deprecaciones Peewee.
5. Definir un procedimiento formal de publicación y respaldo del instalador.
